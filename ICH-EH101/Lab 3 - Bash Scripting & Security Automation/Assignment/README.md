# Lab 3 Assignment — Bash Scripting & Security Automation

## Easy Exercises

1. **Greeting Script:** Ask for the user's name and time of day, then display an appropriate greeting.
2. **File Counter:** Count the number of files in a directory and display the result.
3. **Number Guesser:** Make the computer select a random number and allow the user to guess it.

## Medium Exercises

1. **Password Generator:** Create a Bash script that generates random passwords of a specified length.
2. **User Registration and Password Validation:** Create a command-line registration script that collects a user's name, phone number, and password, then validates the inputs before displaying a success message.

## Submission Requirements

- Submit your PDF files.
- Explain the processes you took for each exercise
- **Attach the necessary screenshots** showing your scripts running successfully.
- Ensure your scripts execute without errors.
- Use fictional information for testing; do not use real passwords or sensitive personal information.

**Note:** Complete all three easy exercises and both medium exercises.
