# Lab 1 — Take-Home Assignment

## Assignment: Security Assessment of a Hypothetical Organization

Choose **one** of the following:

* University
* Bank
* Hospital
* E-commerce company
* Government organization

### Identify:

1. Five assets
2. Five possible threats
3. Five vulnerabilities
4. Five potential risks
5. Five security controls

### Then select one asset and explain:

```text
Asset → Threat → Vulnerability → Risk → Control
```

---

## Submission

Your work should clearly identify the selected organization and provide the required five assets, threats, vulnerabilities, risks, and security controls.

The final section should demonstrate the relationship between:

**Asset → Threat → Vulnerability → Risk → Control**
